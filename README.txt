This package adds the missing website pages without replacing your current homepage.

ADD TO YOUR CURRENT PROJECT
1. Copy all .html files into the main website folder.
2. Copy css/pages.css into the existing css folder.
3. Keep your current css/style.css and js/script.js.
4. Keep the existing images folder and logo files.
5. Replace the homepage header navigation using homepage-navigation-replacement.html.
6. Add <link rel="stylesheet" href="css/pages.css"> after style.css on inner pages
   (already included in every page in this package).
